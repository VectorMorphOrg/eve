# E.V.E. Audits

This directory contains engineering audit reports generated
during the development of E.V.E.

Each release milestone has its own audit package documenting:

- Documentation quality
- Implementation status
- Navigation verification
- Release readiness
- QA results

These reports are historical engineering artifacts and are
retained for traceability.

## Canonical repository map

**Path:** `audits/document-map.md`

This is the single document map for the repository.
Do **not** expect a duplicate at
`audits/v0.6.0-alpha/document-map.md`.
